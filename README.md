# Portafolio profesional — Sergio Vásquez Hincapié

Sitio web estático creado con HTML, CSS y JavaScript. Está preparado para publicarse gratuitamente con GitHub Pages.

## Archivos

- `index.html`: contenido y estructura del portafolio.
- `styles.css`: diseño adaptable a computador, tableta y celular.
- `script.js`: menú móvil, año automático y exportación/impresión a PDF.
- `assets/foto-perfil.svg`: imagen provisional que debes reemplazar por tu fotografía.

## Antes de publicar

1. Reemplaza `assets/foto-perfil.svg` por tu fotografía, preferiblemente JPG o PNG.
2. Si cambias el nombre de la foto, actualiza la ruta en `index.html`.
3. Verifica los datos de formación actual, fechas, cursos y experiencia.
4. Añade tu teléfono cuando quieras hacerlo público.
5. Revisa los enlaces y la ortografía.

## Publicar con GitHub Pages

1. Crea un repositorio público en GitHub, por ejemplo `portafolio-profesional`.
2. Sube `index.html`, `styles.css`, `script.js`, `README.md` y la carpeta `assets`.
3. En el repositorio abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages genere la dirección web. Normalmente tendrá el formato `https://TU-USUARIO.github.io/portafolio-profesional/`.

## Exportar a PDF

El botón **Exportar en PDF** abre la ventana de impresión del navegador. Selecciona **Guardar como PDF** como destino. Para un mejor resultado, activa los gráficos de fondo si el navegador ofrece esa opción.
